Case 1 (required)
Question: What is Mistake 1, and what does the document recommend to fix it?
Answerable from this PDF? Yes
Required answer facts (one fact per line):
 Mistake 1 is "Use Eager Fetching"
 The FetchType defines when Hibernate initializes an association, and it's set via the fetch attribute of @OneToMany, @ManyToOne, @ManyToMany, and @OneToOne annotations
 Eagerly fetched associations are loaded whenever Hibernate loads the owning entity, which can require an additional query for each entity and often causes dozens or hundreds of extra queries
 The recommended fix is to use FetchType.LAZY instead, which delays initialization of the relationship until it's used in business code
Evidence: PDF viewer page 1 — "Mistake 1: Use Eager Fetching / The FetchType defines when Hibernate initializes an association. You can specify with the fetch attribute of the @OneToMany, @ManyToOne, @ManyToMany and @OneToOne annotation. Hibernate loads eagerly fetched associations when it loads an entity... Better use FetchType.LAZY instead. It delays the initialization of the relationship until you use it in your business code."

Case 2 (required)
Question: According to the document, how can you limit the number of records returned by a JPQL query, since JPQL doesn't support OFFSET and LIMIT keywords?
Answerable from this PDF? Yes
Required answer facts (one fact per line):
    JPQL does not support the OFFSET and LIMIT keywords used in SQL
    To limit records, you set the information on the Query interface rather than in the JPQL statement itself
    The code example shows using .setMaxResults(5) and .setFirstResult(0) on the query
Evidence: PDF viewer page 2 — "Mistake 4: Select More Records Than You Need / JPQL doesn't support the OFFSET and LIMIT keywords you use in your SQL query... You just need to set this information on the Query interface and not in the JPQL statement." Boxed code: List<Author> authors = em.createQuery("SELECT a FROM Author a ORDER BY a.id ASC", Author.class).setMaxResults(5).setFirstResult(0).getResultList();
